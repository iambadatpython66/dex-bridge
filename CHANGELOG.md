# Changes

## 1.1.0

- Add Auto mode and capability-based Android support without a phone-model whitelist.
- Mirror Android 5+ devices from Samsung and other manufacturers when desktop capability is unknown.
- Automatically fall back once from failed or frameless virtual desktop to phone mirroring.
- Disable audio below Android 11 and use lighter video/basic keyboard input on Android 5–9.
- Preserve v1.0 manual mode preferences when loading older settings.
- Expand USB driver and input-permission guidance across manufacturers.
- Add reproducible source, tests, compatibility documentation, and a Windows GitHub build workflow.

## 1.0.0

- Initial Windows USB display receiver with virtual desktop and phone-screen modes.
